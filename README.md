## 🇨🇳 简体中文 (zh_CN)

### 插件名称
**图片智能排版导出 PDF / 图片**

### 插件描述
- **简介**：将 Eagle 选中的图片按画册比例、网格或长图自动排版，支持单图微调、圆角描边阴影装饰，一键导出高清 PDF 或图片（PNG/JPG/WebP）。
- **详细介绍**：
  一款专为设计师、摄影师与素材整理者打造的 Eagle 视觉排版与拼图导出工具。无需打开 InDesign 或 Photoshop，即可将选中的多张图片快速排版为专业画册、作品集网格或无缝长图，并一键导出为多页 PDF 文档或高清图片序列。
  - **四大排版模式**：支持「智能画册（整页自适应均衡分配）」、「等分网格」、「长图拼接（纵向/横向）」与「单图单页」。
  - **双格式高清导出**：支持导出多页 PDF 文档，或导出 PNG / JPG / WebP 高清图片（多页时支持合并为一整张全景大图）。
  - **精细视觉装饰**：内置页边距、外框净间距、图片圆角、四边等宽描边、立体柔和阴影、背景色以及页眉/页脚/页码自定义。
  - **画布交互微调**：支持单页精调与多页总览双视图，点击画布任意图片即可独立设置旋转角度、适应/填充模式，或与其它图片交换位置。
  - **灵活纸张规格**：内置 A3 / A4 / A5 / B5、16:9 演示屏、1:1 方画册、9:16 手机竖屏及自定义毫米尺寸，支持 72 ~ 300 DPI 印刷级输出。

### 使用说明
1. **选择素材**：在 Eagle 资源库中选中需要排版的一张或多张图片（也可在打开插件后点击「读取选中」同步最新选中项）。
2. **选择排版模式**：在左侧「布局纸张」面板中选择排版引擎（智能画册 / 等分网格 / 长图拼接 / 单图单页），并设置纸张尺寸、横竖方向与排列规律。
3. **调整边距与样式**：切换至「边距样式」面板，设置页边距、图片水平/垂直间距、圆角、四边描边、立体阴影、背景颜色及文字标签/页眉页脚。
4. **画布预览与单图微调**：
   - 在右侧画布顶栏可切换「单页视图」与「多页总览」。
   - 在单页视图中点击任意图片，可弹出快捷工具条，单独旋转图片（±90°）、切换「完整显示 / 裁切填满」，或点击两张图片快速互换位置。
   - 在「图片列表」面板中可拖拽调整顺序、按文件名/尺寸/比例排序，或移除个别图片。
5. **导出文件**：在「导出设置」中选择输出类型（PDF 文档或 PNG/JPG/WebP 图片）与打印精度（DPI），点击底部「立即导出」即可保存到本地。

## 🇺🇸 English (en)

### Plugin Name
**Smart Image Layout to PDF & Image**

### Plugin Description
- **Summary**: Auto-layout selected Eagle images into balanced albums, uniform grids, or seamless stitches, and export as high-res PDF or images (PNG/JPG/WebP).
- **Full Description**:
  A studio-grade visual layout, contact sheet, and collage export tool built for Eagle. Turn selected images into balanced multi-page lookbooks, uniform portfolio grids, or seamless vertical/horizontal scroll stitches in seconds—without opening InDesign or Photoshop.
  - **4 Layout Engines**: Smart Justified Album (with whole-page balanced row distribution), Uniform Grid, Long Stitch (Vertical/Horizontal), and 1-Image-Per-Page.
  - **Dual Export Formats**: Export as multi-page PDF documents or high-resolution raster images (PNG, JPG, WebP), with an option to merge all pages into a single panoramic sheet.
  - **Rich Visual Styling**: Customize page margins, outer border-to-border spacing, corner radius, uniform 4-sided borders, soft drop shadows, background colors, captions, and headers/footers.
  - **Interactive Canvas Inspection**: Switch between Single-Page View and Multi-Page Overview. Click any image right on the canvas to rotate (±90°), toggle Fit/Cover mode, or swap positions with another image.
  - **Print-Ready Page Presets**: Supports A3, A4, A5, B5, 16:9 Presentation, 1:1 Square Album, 9:16 Mobile Story, and Custom millimeter dimensions at 72 to 300 DPI.

### Usage Guide
1. **Select Images**: Select one or more images in Eagle (or click "Load Selected" inside the plugin to sync your current selection).
2. **Choose Layout Mode**: In the "Layout" tab, pick a layout mode (Smart Album, Uniform Grid, Long Stitch, or Single Page) and configure paper size, orientation, and row arrangement.
3. **Style & Decorate**: Open the "Style" tab to adjust page margins, horizontal/vertical gaps, corner radius, uniform borders, drop shadows, canvas background, captions, and page numbers.
4. **Preview & Fine-Tune on Canvas**:
   - Toggle between "Single Page" and "Overview" in the top canvas toolbar.
   - Click any image in Single Page view to open the floating toolbar: rotate it ±90°, switch between Fit (Contain) and Fill (Cover), or swap it with another image.
   - Use the "Images" tab to drag-and-drop reorder, batch-sort by name/size/aspect ratio, or remove individual items.
5. **Export**: In the "Export" tab, choose PDF or Image (PNG/JPG/WebP) and select your target DPI, then click "Export Now" at the bottom.

### Changelog
- **v2.0.0**
  - [New] Export layouts as high-resolution images (PNG, JPG, WebP), including an option to merge multi-page layouts into a single combined sheet.
  - [New] 4 visual layout engines: Smart Album (defaults to Auto-Fit Balanced Page via dynamic programming), Uniform Grid, Long Stitch (Vertical & Horizontal), and Single Image per Page.
  - [New] Single-Page vs. Multi-Page Overview toggle on the preview canvas for rapid multi-page inspection and navigation.
  - [New] Interactive on-canvas image editor: click any image to rotate, override Fit/Cover mode, or swap positions.
  - [New] Custom preset manager (Save/Apply/Delete) and one-click "Reset".
  - [Improved] Redesigned modern Studio UI with dark/light theme support, quick spacing presets, color swatches, and a sticky export bar.
  - [Fixed] Decoupled horizontal/vertical spacing from border width: spacing now strictly controls outer border-to-border distance, and borders render with 100% uniform width on all four sides.
- **v1.0.0**
  - Initial release with basic multi-image layout and PDF export.

## 🇯🇵 日本語 (ja_JP)

### プラグイン名
**画像スマート自動配置・PDF/画像出力**

### プラグインの説明
- **概要**：Eagleで選択中の画像を画集風・グリッド・縦長結合で自動レイアウトし、高画質PDFまたは画像（PNG/JPG/WebP）として一括書き出しします。
- **詳細説明**：
  デザイナー、フォトグラファー、素材コレクター向けのEagle専用レイアウト＆コラージュ出力ツールです。InDesignやPhotoshopを開かなくても、選択した複数の画像を美しい画集、ポートフォリオ用グリッド、またはシームレスな長尺画像に自動配置し、マルチページPDFや高解像度画像としてワンクリックで書き出せます。
  - **4つのレイアウトモード**：「スマート画集（ページ全体の自動均等配分）」「均等グリッド」「長尺結合（縦／横）」「1ページ1画像」を搭載。
  - **PDF＆高画質画像出力**：マルチページPDF書類のほか、PNG / JPG / WebP画像での書き出しに対応（複数ページを1枚のパノラマ画像に結合して出力することも可能）。
  - **豊富な装飾スタイル**：ページ余白、枠線間の水平・垂直間隔、角丸、四辺均等ボーダー、ドロップシャドウ、背景色、キャプション、ヘッダー／フッター／ページ番号を自在に調整可能。
  - **キャンバス上での個別編集**：「単ページ表示」と「全体一覧」をワンクリックで切り替え。キャンバス上の画像をクリックして個別に回転（±90°）、表示モード（全体表示／トリミング充填）の切り替え、画像の位置入れ替えが可能。
  - **多彩な用紙サイズ**：A3 / A4 / A5 / B5、16:9スライド、1:1正方形ブック、9:16スマホ縦画面、カスタム寸法（mm）に対応し、72〜300 DPIの印刷品質で出力可能。

### 使い方（使用説明）
1. **画像を選択**：Eagleライブラリでレイアウトしたい画像を1枚以上選択します（プラグイン起動後に「選択画像を更新」をクリックして再取得することも可能です）。
2. **レイアウト選択**：左側の「配置・用紙」タブでレイアウトモード（スマート画集／均等グリッド／長尺結合／1ページ1画像）、用紙サイズ、向き、行の配置ルールを選択します。
3. **余白とスタイル調整**：「余白・装飾」タブでページ余白、画像の水平・垂直間隔、角丸、四辺枠線、シャドウ、背景色、ファイル名ラベルやページ番号を設定します。
4. **プレビューと個別調整**：
   - キャンバス上部のツールバーで「単ページ」と「全体一覧」を切り替えられます。
   - 単ページ表示で任意の画像をクリックすると、個別ツールバーが表示され、回転（±90°）、フィット／カバー切り替え、他の画像との入れ替えが行えます。
   - 「画像一覧」タブではドラッグ＆ドロップでの並び替えや、名前・サイズ・比率順の一括ソートが可能です。
5. **書き出し**：「出力設定」タブで出力形式（PDF書類またはPNG/JPG/WebP画像）と解像度（DPI）を選択し、下部の「書き出す」をクリックします。
